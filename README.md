# blue-team-notes

# > 网络安全蓝队学习笔记与应急响应脚本仓库

# 

# 📖 项目简介

# 本仓库用于记录蓝队安全学习内容，包含 Windows / Linux 主机应急排查、进程端口审计、系统日志分析、基础恶意行为排查脚本，用于巩固安全运维、主机检测、应急响应相关知识。

# 适合蓝队岗位学习，可用于主机入侵排查、异常流量初步定位、系统状态巡检。

# 

# 📂 仓库目录规划（后续新建文件夹）

# \- `windows/`：Windows应急排查命令、PowerShell检测脚本、事件日志分析笔记

# \- `linux/`：Linux主机排查，进程、端口、登录日志、恶意文件排查

# \- `scripts/`：自用简单巡检脚本（Python / PowerShell）

# \- `notes/`：学习笔记、NISP、CTF蓝队相关知识点

# 

# &#x20;🛠️ 技术栈

# \- PowerShell

# \- Python

# \- Windows 事件日志、Sysmon

# \- Linux 基础审计命令（netstat、ss、lsof、auditd）

# 

# ✨ 学习目标

# 1\. 掌握主机层面异常进程、端口、自启动项排查

# 2\. 看懂系统日志，识别可疑登录与恶意行为

# 3\. 编写自动化巡检脚本，简化应急排查流程

# 4\. 积累蓝队实战经验，用于安全运维/蓝队岗位求职

# 

# 📜 说明

# 本项目仅用于网络安全学习，所有脚本仅在自己授权环境内测试，禁止用于未授权的系统检测。
